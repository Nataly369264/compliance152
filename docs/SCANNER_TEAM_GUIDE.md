## ЧАСТЬ 1 — Инструкция для администратора (Марина)

### Что нужно сделать, чтобы команда могла запускать скрипты

#### 1. Добавить email участника в Google Cloud Console

1. Открой https://console.cloud.google.com/auth/audience?project=compliance152
2. Раздел **"Тестовые пользователи"** → **"+ Add Users"**
3. Введи email участника → **"Сохранить"**

Максимум 100 тестовых пользователей. Без этого участник получит ошибку "Доступ заблокирован".

#### 2. Передать участнику файл credentials.json

Файл находится в `config/credentials.json`. Передай его **лично** (мессенджер, email) — не через git, не через общий чат. Файл содержит ключи OAuth-приложения.

#### 3. Добавить участника в Google Sheets

Открой таблицу → **"Поделиться"** → введи email участника → выбери права **"Редактор"**.

#### 4. Сообщить участнику ID таблицы

```
GOOGLE_SHEET_ID=1ag4869fMutJAB0zL4BZSvjdAX0G4QltRe4iLSpOrULU
```

### Как запустить тест через Claude Code (для Марины)

#### Вариант А — передать вывод сканера текстом

Скопируй результат из UI сканера и напиши Claude Code:

```
Заполни таблицу по результатам прогона:
[вставь сюда вывод сканера]
```

Claude Code сам распарсит результат, запишет строки в Google Sheets и создаст задачи по расхождениям.

#### Вариант Б — запустить golden scan и сразу записать

```
Запусти golden scan на https://site.ru и запиши результаты в Google Sheets
```

#### Вариант В — записать из готового JSON-файла

Если есть файл прогона в `tests/fixtures/golden_runs/`:

```
python scripts/update_gsheets.py tests/fixtures/golden_runs/site_2026-05-06.json
```

### Как устроена таблица

| Лист | Что содержит | Кто заполняет |
|------|-------------|---------------|
| **Прогоны** | Лог каждого запуска: сайт, score, дата, точность | Скрипт автоматически |
| **Результаты** | Детальные результаты по каждому пункту | Скрипт + ты вручную (тип расхождения) |
| **Задачи** | Баг-трекер: расхождения сканера с эталоном | Скрипт автоматически |
| **Эталон** | Справочник ручных проверок (37 пунктов × сайты) | Заполняется один раз вручную |

### Колонки, которые заполняются вручную

На листе **Результаты** после каждого прогона проверь и при необходимости поправь:

- `тип_расхождения` — если скрипт поставил `false positive`, а на самом деле `сайт изменился` — исправь
- `комментарий` — добавь контекст, если знаешь причину

На листе **Задачи**:
- `статус` — меняй с `открыта` на `в работе` / `исправлено` / `не воспроизводится`
- `дата_закрытия` — проставь когда закрываешь задачу
- `комментарий_после_фикса` — что именно исправили в сканере

## ЧАСТЬ 2 — Инструкция для участника команды

### Разовая настройка (делается один раз)

#### Шаг 1. Получи от Марины

- Файл `credentials.json`
- Строку `GOOGLE_SHEET_ID=1ag4869fMutJAB0zL4BZSvjdAX0G4QltRe4iLSpOrULU`

#### Шаг 2. Положи credentials.json в проект

```
c:\...\compliance152\config\credentials.json
```

#### Шаг 3. Добавь в файл .env

Открой файл `.env` в корне проекта и добавь строку:

```
GOOGLE_SHEET_ID=1ag4869fMutJAB0zL4BZSvjdAX0G4QltRe4iLSpOrULU
```

#### Шаг 4. Установи зависимости

```bash
pip install gspread google-auth-oauthlib google-auth-httplib2
```

#### Шаг 5. Пройди авторизацию (один раз)

```bash
python scripts/auth_google.py
```

Откроется браузер → войди в свой Google-аккаунт → нажми **"Разрешить"**.
Если увидишь "Приложение не проверено" → нажми **"Дополнительно"** → **"Перейти на compliance152"**.

После этого в папке `config/` появится `token.json`. Больше авторизация не нужна.

### Как работать с таблицей

#### Просмотр результатов

Просто открой таблицу в браузере:
https://docs.google.com/spreadsheets/d/1ag4869fMutJAB0zL4BZSvjdAX0G4QltRe4iLSpOrULU

Цветовые обозначения в колонке **"сравнение"**:
- 🟢 `✓` — сканер совпал с эталоном
- 🔴 `РАСХОЖДЕНИЕ` — сканер и эталон расходятся, нужен разбор
- 🟡 `НУЖНА ПРОВЕРКА` — нет данных для сравнения

Цветовые обозначения в колонке **"серьёзность"**:
- 🔴 `критично` — сканер пропустил реальное нарушение (false negative)
- 🟡 `важно` — сканер ложно нашёл нарушение (false positive)
- `минор` — новая находка, требует верификации

#### Запись результатов через Claude Code

Открой Claude Code в папке проекта и напиши:

**Если у тебя есть текстовый вывод сканера:**
```
Заполни таблицу по результатам прогона:
[вставь вывод сканера сюда]
```

**Если хочешь запустить сканер на конкретном сайте:**
```
Запусти golden scan на https://site.ru и запиши в Google Sheets
```

**Если есть готовый JSON-файл прогона:**
```bash
python scripts/update_gsheets.py tests/fixtures/golden_runs/site_2026-05-06.json
```

#### Заполнение вручную после прогона

После того как скрипт записал результаты, зайди в таблицу и:

1. **Лист "Результаты"** — для строк с `РАСХОЖДЕНИЕ` проверь колонку `тип_расхождения`:
   - Если сайт изменился с момента ручной проверки → измени на `сайт изменился`
   - Если скрипт ошибся в классификации → исправь вручную

2. **Лист "Задачи"** — найди задачи по своим пунктам и:
   - Поставь статус `в работе` если взял в работу
   - Поставь `исправлено` после фикса в коде сканера
   - Заполни `комментарий_после_фикса`

#### Обновление эталона

Если ты провёл ручную проверку нового сайта — добавь результаты на лист **"Эталон"** вручную или через Claude Code:

```
Добавь в лист Эталон результаты ручной проверки site.ru:
пункт 1 — Да
пункт 2 — Нет
...
```

---

### Что НЕ делать

- Не коммить `config/credentials.json` и `config/token.json` в git — они в .gitignore
- Не удалять строки из листа "Эталон" — это эталонные данные
- Не менять формулы в колонках `результат_эталон` и `сравнение` — они считаются автоматически

---

### Если что-то пошло не так

| Ошибка | Решение |
|--------|---------|
| `Token has been expired or revoked` | Удали `config/token.json` и запусти `auth_google.py` снова |
| `Доступ заблокирован: приложение не прошло проверку` | Попроси Марину добавить твой email как тестового пользователя |
| `APIError: The caller does not have permission` | Попроси Марину дать тебе права редактора в Google Sheets |
| `FileNotFoundError: credentials.json` | Получи файл у Марины и положи в `config/` |
